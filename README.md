# Smart Student Expense Tracker\
\
A Python desktop application for students to track expenses and manage monthly budgets.\
\
## Features\
- Add expenses by category\
- Track total spending and remaining budget\
- Receive overspending warnings\
- View expense history\
- Automatically save and restore data using JSON\
- Reset the tracker\
- Handle invalid inputs\
\
## Technologies Used\
- Python\
- Tkinter\
- JSON\
\
## How to Run\
1. Install Python with Tkinter support.\
2. Download expense_tracker.py.\
3. Open it in Python IDLE.\
4. Press F5 to run the application.\
\
